# AutoSolace CRM

A personal CRM for managing car sales contacts, deals, and follow-up reminders.

PRD: https://claude.ai/artifact/LTuEeRQB98MZmAWyosVLsz

## Stack

- [Next.js](https://nextjs.org) (App Router, TypeScript)
- [Prisma](https://www.prisma.io) + SQLite
- Deployed on [Railway](https://railway.app)

## Getting started

```bash
npm install
npx prisma migrate dev
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
